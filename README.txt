1. Unzip this folder.
2. Open it in VS Code (File > Open Folder).
3. Install the 'Live Server' extension, right-click index.html > Open with Live Server.
   (Or just double-click index.html to open it in your browser.)

Needs internet once for the Google Fonts; it falls back to system fonts offline.
Edit text in index.html and colors in style.css (see :root at the top).
