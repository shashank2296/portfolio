# Kovuru Sai Shashank | Portfolio

A car-themed personal portfolio website built with plain HTML and CSS. It shows my skills, projects, experience, achievements, and education on a night-drive background with an animated sports car.

**Live site:** https://shashank2296.github.io/portfolio/

## Features

- Night city and road background with moving lane dashes and light streaks
- Hero section where a sports car drives in and its wheels spin
- Sticky navigation bar with smooth scrolling
- Frosted-glass content panels for easy reading
- Sections for About, Skills, Projects, Experience, Achievements and Certificates, Education, and Contact
- Responsive layout for phones, tablets, and desktops
- Animations turn off for visitors who prefer reduced motion

## Built with

- HTML5 and inline SVG for the page and the car artwork
- CSS3 (variables, Flexbox, Grid, keyframe animations)
- Google Fonts: Big Shoulders Display and Barlow
- No JavaScript, frameworks, or build tools

## Project structure

```
portfolio/
├── index.html    # page content
├── style.css     # design and animations
└── README.md
```

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/shashank2296/portfolio.git
   cd portfolio
   ```
2. Open `index.html` in your browser, or use the **Live Server** extension in VS Code (right-click `index.html` and choose **Open with Live Server**).

An internet connection is needed once to load the Google Fonts. Without it, the page falls back to system fonts.

## Customize

- Edit your text in `index.html`.
- Change colors in the `:root` block at the top of `style.css`.

## Deploy

The site is hosted with GitHub Pages: **Settings > Pages > Deploy from a branch > `main` / root**.
